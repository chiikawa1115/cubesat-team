## 1. 天線場型 → 指向需求正向推導

### 1.1 設計邏輯（v1.0 錯誤 vs. v1.1 正確）

**v1.0 做法（邏輯反轉，已廢棄）：**
> 先假設 ADCS 精度 ±3°，然後聲稱 "margin 足夠"。無法說明 ±3° 從何而來。

**v1.1 正向推導流程：**

```
S-band Patch 天線參數 (G=8 dBi, f=2 GHz)
    │
    ▼
估算 Half-Power Beamwidth (HPBW ≈ 70°)
    │
    ▼
設定可接受指向損耗預算 (≤ 1 dB)
    │
    ▼
由 Gain pattern 計算最大允許 off-axis 角度 θ_max
    │
    ▼
θ_max 即為 ADCS 指向精度的「不可超越上限」
    │
    ▼
除以 Safety Factor (3σ)  →  ADCS 指向精度規格
    │
    ▼
選型 COTS ADCS → 確認精度 ≤ 規格
```

### 1.2 天線場型估算

**天線參數：**

| 參數 | 值 | 備註 |
|------|----|------|
| 天線類型 | S-band Rectangular Patch | 2 GHz, n236 band |
| 峰值增益 G_max | 8 dBi | 典型 S-band patch 增益 |
| 頻率 | 2 GHz | S-band NTN n236 |
| HPBW (3 dB 全寬) | ≈ 70° | patch 天線典型值 |
| HPBW 半角 θ_3dB | ≈ 35° | 半功率半角 |

**Gaussian 場型近似模型：**

Patch 天線的主波束可用 Gaussian beam 近似：

$$G(\theta) = G_{\max} \cdot \exp\!\left(-4\ln 2 \cdot \left(\frac{\theta}{\text{HPBW}}\right)^2\right)$$

其中 HPBW 為全寬 70°。此模型在主波束範圍內（±35°）的誤差 < 0.5 dB，適用於 Phase A 估算。

**驗證 3 dB 點：** 當 θ = HPBW/2 = 35° 時：

```
G(35°)/G_max = exp(-4·ln2·(35/70)²) = exp(-ln2) = 0.5  →  -3.01 dB  ✓
```

### 1.3 各損耗對應的最大 Off-Axis 角度

由 Gaussian 模型反算各損耗等級對應的最大偏軸角度：

| 指向損耗 (dB) | 最大 Off-Axis 角度 θ (deg) | 殘餘增益 (dBi) | 備註 |
|:---:|:---:|:---:|------|
| 0.5 | 14.3° | 7.5 | 保守設計上限 |
| **1.0** | **20.2°** | **7.0** | **本案設計點** |
| 1.5 | 24.7° | 6.5 | — |
| 2.0 | 28.5° | 6.0 | — |
| 3.0 | 35.0° | 5.0 | HPBW 邊界 |

**計算過程（1 dB 損耗）：**

```
設 ΔG = -1 dB，即 G(θ)/G_max = 10^(-0.1) = 0.7943

0.7943 = exp(-4·ln2·(θ/70)²)

ln(0.7943) = -4·ln2·(θ/70)²

-0.2303 = -2.7726·(θ/70)²

(θ/70)² = 0.2303 / 2.7726 = 0.08307

θ/70 = 0.2882

θ = 0.2882 × 70° = 20.17° ≈ 20.2°
```

**結論：當衛星指向偏離 boresight 超過 ±20.2° 時，天線增益損耗超過 1 dB。**

### 1.4 ADCS 指向精度需求推導

從最大允許 off-axis 角度推導 ADCS 規格：

| 參數 | 值 | 說明 |
|------|----|------|
| 最大允許 off-axis θ_max | 20.2° | 對應 1 dB 損耗 |
| Safety factor (3σ) | 3 | 99.7% 信賴區間 |
| **ADCS 指向精度需求 (1σ)** | **±6.7°** | = 20.2° / 3 |
| Safety factor (2σ) | 2 | 95.4% 信賴區間 |
| ADCS 指向精度需求 (1σ) | ±10.1° | = 20.2° / 2 |

### 1.5 與 v1.0 的比較

| 項目 | v1.0（假設） | v1.1（正向推導） | 差異 |
|------|:---:|:---:|------|
| ADCS 指向精度 | ±3° | ±6.7° (3σ) | v1.1 **更寬鬆**，減輕 ADCS 負擔 |
| 推導依據 | 無（直接假設） | 天線場型 + 損耗預算 | v1.1 有完整推導鏈 |
| 天線增益損耗預算 | 未定義 | ≤ 1 dB | 明確可追溯 |
| Link margin 影響 | 不明 | 1 dB loss 已在 link budget 中列帳 | 與 COM 子系統介面一致 |

**重要發現：** S-band patch 天線的 HPBW 很寬（70°），正向推導出的 ADCS 需求（±6.7°）比原先假設的 ±3° **寬鬆超過兩倍**。這代表：

1. ADCS 選型可使用較低精度（較低成本）的元件
2. 極區磁力矩器死區造成的暫態指向偏差有更大的容忍空間
3. 即使取保守的 0.5 dB 損耗（θ_max=14.3°, 3σ → ±4.8°），仍比 v1.0 的 ±3° 寬鬆

### 1.6 建議採用值

考量以下因素，建議 ADCS 指向精度規格為 **±5°（3σ）**：

- 正向推導極限值 ±6.7°（1 dB 損耗, 3σ）
- 預留 1.7° margin 應對其他擾動（antenna mounting error, thermal distortion）
- ±5° 對應的指向損耗：G(5°×3 = 15°) = -0.55 dB（正常操作 1σ）
- 此值在多數 COTS CubeSat ADCS 能力範圍內

## 2. SSO 500 km 極區磁力矩器死區分析

### 2.1 軌道參數

| 參數 | 值 | 備註 |
|------|----|------|
| 軌道高度 h | 500 km | LEO |
| 軌道半徑 r | 6871 km | R_E + h |
| 軌道傾角 i | 97.4° | SSO（太陽同步） |
| 軌道週期 T | 94.5 min | — |
| 最大副星點緯度 | 82.6° | = 180° - 97.4° |
| 每圈極區通過次數 | 2 次 | 北極 + 南極各一次 |

### 2.2 極區通過時間計算

**軌道幾何：** 衛星副星點（Sub-Satellite Point）的緯度為：

```
φ(u) = arcsin(sin(i) · sin(u))
```

其中 u 為 argument of latitude（0°~360°），i 為軌道傾角。

**反算超過某緯度的角度範圍：** 設極區門檻緯度為 φ_0，則：

```
sin(φ_0) = sin(i) · sin(u)
u_1 = arcsin(sin(φ_0) / sin(i))
u_2 = 180° - u_1
Δu = u_2 - u_1（每次通過的角度範圍）
t_pass = (Δu / 360°) × T_orbit
```

**計算結果：**

| 極區門檻緯度 | 角度範圍 Δu | 每次通過時間 | 每圈總時間（2次） | 佔軌道比例 |
|:---:|:---:|:---:|:---:|:---:|
| > 70° | 37.3° | 9.8 min (587 s) | 19.6 min | 20.7% |
| > 75° | 26.2° | 6.9 min (412 s) | 13.7 min | 14.5% |
| **> 80°** | **13.5°** | **3.5 min (212 s)** | **7.1 min** | **7.5%** |
| > 82° | 6.1° | 1.6 min (96 s) | 3.2 min | 3.4% |

**以 80° 為極區磁場死區門檻：每次通過約 3.5 分鐘，每圈 7.1 分鐘，佔軌道週期 7.5%。**

### 2.3 磁場方向與磁力矩器死區機制

**地磁場偶極模型：** 在高緯度地區（φ > 80°），地磁場幾乎完全垂直地面，指向地心方向。

**衛星 Body Frame 定義（Nadir-Pointing 模式）：**

| 軸 | 方向 | 說明 |
|----|------|------|
| X (Roll) | 飛行方向（velocity） | 沿軌道前進 |
| Y (Pitch) | 軌道法向（orbit normal） | 垂直軌道面 |
| Z (Yaw) | 天底（nadir） | 指向地心 |

**極區磁場方向分析：**

在極區，地磁場 **B** 幾乎與衛星 Z 軸（nadir）平行：

```
B ≈ B_z · ẑ     （在極區，B_x ≈ 0, B_y ≈ 0）
```

**磁力矩器力矩公式：** τ = **m** × **B**

| 磁力矩器 | 磁偶極方向 | 叉積結果 | 產生力矩 | 極區狀態 |
|----------|-----------|---------|---------|---------|
| MTQ-X | m_x · x̂ | m_x × B_z (x̂ × ẑ) | τ_y (Pitch) | **正常** |
| MTQ-Y | m_y · ŷ | m_y × B_z (ŷ × ẑ) | τ_x (Roll) | **正常** |
| MTQ-Z | m_z · ẑ | m_z × B_z (ẑ × ẑ) | **= 0** | **死區** |

**結論：在極區，Z 軸（Yaw）方向的磁力矩器完全無法產生力矩。** 這是因為磁偶極方向與外部磁場方向平行，叉積為零。

### 2.4 受影響的控制軸

```
                   極區 B 場 ≈ 沿 Z 軸（nadir）
                          │
                          ▼
    ┌─────────────────────────────────────────┐
    │  MTQ-X × B_z → Pitch 力矩    ✓ 可控    │
    │  MTQ-Y × B_z → Roll 力矩     ✓ 可控    │
    │  MTQ-Z × B_z → 0             ✗ 死區    │
    └─────────────────────────────────────────┘
                          │
                 ★ Yaw 軸控制失效 ★
```

**影響程度：**

- **完全失效時間：** 每次極區通過（lat > 80°）約 3.5 min，占軌道 7.5%
- **部分降低時間：** lat > 70° 區間約 9.8 min，此時 Yaw 控制能力顯著降低但未完全為零
- **累積效應：** 每圈 2 次極區通過，若 Yaw 軸存在外部擾動力矩，角動量無法卸載，反應輪將逐漸飽和

### 2.5 緩解策略

#### 策略 A：磁力矩器 ×3 + 微型反應輪 ×1（Yaw 軸補償）★ 推薦

| 項目 | 說明 |
|------|------|
| 配置 | 3 軸磁力矩器 + 1 個反應輪（安裝在 Z 軸） |
| 原理 | 反應輪提供 Yaw 軸力矩，不依賴外部磁場；磁力矩器在低緯度區卸載反應輪角動量 |
| 極區行為 | 反應輪獨立控制 Yaw，磁力矩器繼續控制 Roll/Pitch |
| 角動量管理 | 低緯度段（占軌道 ~80%）磁力矩器進行 momentum dumping |
| 質量影響 | 微型反應輪 ≈ 30–60 g（如 CubeWheel Small），1U ADCS 可容納 |
| 成本影響 | 增加約 $5k–$15k（取決於供應商） |
| 可行性 | **高**。這是 CubeSat 最常見的配置，COTS 元件成熟 |

**角動量卸載時序分析：**

```
極區通過 (lat>80°, 3.5 min):
  → MTQ-Z 無效，但 RW-Z 維持 Yaw 控制
  → RW-Z 累積角動量 ≈ τ_disturbance × t = 10⁻⁷ Nm × 210 s ≈ 2×10⁻⁵ N·m·s

低緯度段 (~40 min between polar passes):
  → MTQ-Z 恢復功能，對 RW-Z 進行 momentum dump
  → 典型 MTQ 力矩 ~10⁻⁴ Nm，卸載時間 ≈ 0.2 s（完全足夠）
```

**結論：** 極區累積的角動量極小，低緯度段有充裕時間卸載，RW 不會飽和。

#### 策略 B：容忍暫態偏差（Attitude Error Relaxation）

| 項目 | 說明 |
|------|------|
| 配置 | 純磁力矩器 ×3（不加反應輪） |
| 原理 | 在極區通過期間（~3.5 min/次），允許 Yaw 軸較大的指向誤差 |
| 容忍範圍 | 根據 §1.4，指向精度需求 ±6.7°（3σ），即使 Yaw 漂移數度仍在天線 HPBW 內 |
| 極區通訊 | 極區通常不是 NTN 通訊的主要服務區（高緯度地面站少），暫態偏差影響有限 |
| 優勢 | 無額外硬體，質量/成本/功耗最低 |
| 風險 | 若極區恰有通訊需求，link margin 可能不足；Yaw 漂移可能耦合到 Roll/Pitch |
| 可行性 | **中**。可作為 Phase A baseline，但需 Phase B 仿真驗證漂移量級 |

**Yaw 漂移估算：**

```
極區通過時間：t = 212 s
主要 Yaw 擾動力矩：重力梯度 τ_gg ≈ 10⁻⁷ Nm (3U CubeSat)
3U 慣量矩（Z 軸）：I_z ≈ 0.02 kg·m²

角加速度：α = τ/I = 10⁻⁷ / 0.02 = 5×10⁻⁶ rad/s²
極區期間累積角速度：ω = α·t = 5×10⁻⁶ × 212 = 1.06×10⁻³ rad/s
累積角度偏移：Δθ = ½·α·t² = ½ × 5×10⁻⁶ × 212² = 0.112 rad ≈ 6.4°
```

**注意：** 6.4° 已接近 1 dB 損耗上限（20.2°）的 1/3 (6.7°, 3σ)。若初始誤差非零或擾動更大，可能超出指向需求。因此策略 B 風險較高，僅作為 fallback。

#### 策略比較總結

| 評估項目 | 策略 A（MTQ×3 + RW×1） | 策略 B（純 MTQ×3） |
|---------|:---:|:---:|
| Yaw 極區控制 | 完全覆蓋 | 失效 ~7.5% 軌道時間 |
| 最大 Yaw 漂移（極區） | < 0.1°（RW 主動控制） | ≈ 6.4°（開環漂移） |
| 額外質量 | +30~60 g | 0 |
| 額外成本 | +$5k~$15k | $0 |
| 額外功耗 | +0.1~0.3 W | 0 |
| 風險等級 | 低 | 中~高 |
| **建議** | **★ Phase A baseline** | Fallback / 備案 |

### 3.3 選型建議

**推薦方案：NewSpace 模組化配置（MTQ×3 + RW×1）**

| 評估面向 | 分析 |
|---------|------|
| 指向精度 | 3–5° (3σ) 符合 ±5° 需求 |
| 極區覆蓋 | RW 在 Z 軸提供 Yaw 控制，MTQ 卸載 |
| 質量 | ≈ 250 g，低於 500 g 上限 |
| 功耗 | ≈ 0.8 W（平均），低於 2 W 上限 |
| 成本 | ~$30k，為全整合方案的 1/3 ~ 1/2 |
| 風險 | 中（需自行整合，但元件成熟度高） |

**備選方案：CubeSpace CubeADCS 3-Axis**

- 若預算允許，全整合方案降低系統整合風險
- 精度遠超需求（1° vs. 5°），但提供額外 margin
- 含 3 個反應輪，極區覆蓋完整且有冗餘

**已排除方案：**

- Blue Canyon XACT-15：精度過剩（0.003° vs. 5°），成本與質量都超出 3U 預算
- 純磁力矩器方案：Yaw 極區死區風險過高（§2.5 策略 B 分析）

### 3.4 成本影響

| 方案 | ADCS 成本 | vs. v1.0 差異 | 備註 |
|------|----------|:---:|------|
| v1.0 假設（±3°, 全整合） | ~$80k | baseline | 當時未定選型 |
| v1.1 推薦（模組化 MTQ+RW） | ~$30k | **-$50k** | 需求放寬 → 低成本方案可行 |
| v1.1 備選（CubeSpace） | ~$80k | ±$0k | 全整合，風險較低 |

**正向推導的直接效益：** 指向需求從 ±3° 放寬到 ±5°，使得低成本模組化方案成為可行選項，潛在節省 $50k。

## 5. 關鍵假設與待辦事項

### 假設清單

| # | 假設 | 影響 | 待驗證 |

## 附錄 B：Gaussian Beam 場型公式推導

**起點：** 均勻圓形口徑天線的遠場 pattern 可用 Airy function 描述，但在主波束內，Gaussian 近似精度足夠：

```
G(θ) / G_max = exp(-4·ln(2)·(θ / HPBW)²)
```

**1 dB 點推導：**

```
10·log₁₀(G(θ)/G_max) = -1 dB

10·log₁₀(exp(-2.7726·(θ/HPBW)²)) = -1

-2.7726·(θ/HPBW)² · 4.3429 = -1

(θ/HPBW)² = 1 / (2.7726 × 4.3429) = 1 / 12.04 = 0.08307

θ = HPBW × √0.08307 = HPBW × 0.2882

θ = 70° × 0.2882 = 20.17°
```

**3 dB 點驗證：**

```
θ_3dB = HPBW × √(1 / (4·ln(2)·4.3429))  ... 但直接代入：
G(HPBW/2) / G_max = exp(-2.7726·(0.5)²) = exp(-0.6931) = 0.500 → -3.01 dB  ✓
```
