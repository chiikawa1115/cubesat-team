## 2. 任務概述（摘自 ConOps v1）

**任務名稱**：TASA-NTN-3U
**任務類型**：低軌道 IoT-NTN 通訊技術驗證
**主要目標**：
1. 驗證 3GPP Rel-17 NTN 標準在低軌道（500 km）環境下的 S-band 通訊可行性。
2. 展示 3U CubeSat 平台在 SSO 軌道執行 IoT-NTN 中繼服務的能力。
3. 建立台灣自主 NTN 酬載技術與飛行驗證數據庫。

**軌道描述**：
- 軌道高度：500 km ±50 km 圓軌
- 軌道類型：太陽同步軌道（SSO），地方時升交點（LTAN）10:30
- 軌道週期：約 94.7 分鐘
- 每日過境次數（臺灣地面站）：4–6 次（>10° 仰角），過境窗口約 8–12 分鐘

**通訊架構**：
- 上行（UE → 衛星）：S-band n236，1980–2010 MHz，QPSK 1/2
- 下行（衛星 → 地面站）：S-band n236，2170–2200 MHz
- 目標 UE：地面 IoT 終端，線極化天線（與衛星 RHCP 天線存在極化失配，損耗 3.0 dB，已入冊 PATCH-P1）

**任務架構（Stakeholder）**：
- 任務主管機關：TASA（台灣太空中心）
- 地面站：TASA 新竹地面站
- 發射載具：待定（P-POD 3U 相容）

## 附錄 A：Wave 2 Agent 需求對齊速查表

> 提供 Sprint 3 Wave 2 各執行 agent 快速定位其負責範圍的關鍵需求 ID。

### A.1 通訊酬載 Agent（S-band / Link Budget）
**關鍵需求**：
- `SYS-009`：UL Link Margin ≥3 dB @10° 仰角（核心驗證目標）

- `SYS-011`：≥100 bps，QPSK 1/2
- `IFC-003`：OBC ↔ S-band 酬載 LVDS @50 Mbps + SPI @1 MHz

**注意**：PATCH-P1 極化失配 3.0 dB 已計入 SYS-009，鏈路預算文件需標註。

### A.2 EPS Agent（電源系統）
**關鍵需求**：
- `SYS-005`：峰值功耗 ≤10.3 W
- `SYS-006`：電池 DoD ≤30%（實測 25.2%，DCN-002 後滿足）
- `SYS-007`：太陽能板 ≥6.5 W BOL（DCN-001 後）
