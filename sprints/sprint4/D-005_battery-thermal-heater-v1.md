## 1. 目的與範圍

本文件評估 3U CubeSat 電池模組（Samsung INR18650-35E 2S2P）在最惡劣軌道熱環境下，
0.75 W 加熱片是否足以維持電池溫度 ≥ −20°C（運作下限）及 ≥ 0°C（充電許可下限）。
對應 CDR Soft Gate **Q4**：Heater Adequacy。

## 3. 熱模型假設

本文件採用**集總熱容模型（Lumped Thermal Capacitance Model）**，忽略衛星內部
空間溫度梯度，以等效單節點代表衛星整體熱平衡。此為初步評估適用之保守方法。

**有效熱容量估算：**

| 部件 | 質量 m | 比熱 Cp | 熱容 mCp |
|------|--------|---------|----------|
| Al6061 結構 | 300 g | 896 J/kgK | 268.8 J/K |
| 電池模組（Li-ion） | 280 g | 900 J/kgK | 252.0 J/K |
| PCB 電路板 | 100 g | 1000 J/kgK | 100.0 J/K |
| **總計 C_total** | | | **620.8 J/K** |

**電池溫度修正：**
電池位於 −Z 端，與外殼之間有 PCB 間隔及部分氣隙（在地面），
假設電池溫度 ≈ 衛星節點溫度 − 5°C（隔熱效果使電池更冷）。

## 4. Cold Case 熱平衡分析（最惡劣情況）

### 4.1 分析條件

- β角 ≈ 0°，最長食月 35 min（食月比 36.5%）
- 太陽照射面：大側面（A_sun = 0.03405 m²），α = 0.20
- SafeMode 功耗 3.18 W，加熱片 0.75 W（持續開啟）

### 4.2 各段熱輸入

**日照段（佔 63.5%）：**

```
Q_solar   = α × A_sun × G_sun
          = 0.20 × 0.03405 × 1361
          = 9.27 W

Q_in_day  = Q_solar + P_internal + P_heater
          = 9.27 + 3.18 + 0.75
          = 13.20 W
```

**食月段（佔 36.5%）：**

```
Q_in_eclipse = P_internal + P_heater
             = 3.18 + 0.75
             = 3.93 W
```

**軌道平均熱輸入：**

```
Q_in_avg = Q_in_day × 0.635 + Q_in_eclipse × 0.365
         = 13.20 × 0.635 + 3.93 × 0.365
         = 8.382 + 1.434
         = 9.82 W
```

### 4.3 穩態平均溫度（集總節點）

輻射平衡方程：

```
Q_in_avg = ε × σ × A_total × T_mean⁴

T_mean⁴ = Q_in_avg / (ε × σ × A_total)
        = 9.82 / (0.80 × 5.67×10⁻⁸ × 0.15620)
        = 9.82 / (7.083×10⁻⁹)
        = 1.386×10⁹  K⁴

T_mean = (1.386×10⁹)^0.25
       ≈ 192.8 K  =  −80.4°C
```

> **衛星平均溫度 ≈ −80°C**，遠低於設計目標。

### 4.4 溫度振盪分析（食月最低溫）

**熱時間常數（at T_mean = 193 K）：**

```
τ = C_total / (4 × ε × σ × A_total × T_mean³)
  = 620.8 / (4 × 0.80 × 5.67×10⁻⁸ × 0.15620 × 193³)
  = 620.8 / (4 × 0.80 × 5.67×10⁻⁸ × 0.15620 × 7,189,057)
  = 620.8 / (4 × 0.80 × 0.06368)
  = 620.8 / 0.2037
  = 3048 s ≈ 50.8 min
```

**食月期間冷卻幅度：**

日照穩態溫度（以 Q_in_day 平衡）：
```
T_ss_day⁴ = 13.20 / 7.083×10⁻⁹ = 1.864×10⁹
T_ss_day  = 207.8 K  =  −65.4°C
```

食月穩態溫度（以 Q_in_eclipse 平衡）：
```
T_ss_eclipse⁴ = 3.93 / 7.083×10⁻⁹ = 5.549×10⁸
T_ss_eclipse  = 153.2 K  =  −120.0°C
```

指數衰減近似（τ = 50.8 min，食月 35 min）：
```
ΔT_max  = T_ss_day − T_ss_eclipse = 207.8 − 153.2 = 54.6 K

衰減比例 = 1 − e^(−t_eclipse / τ)
         = 1 − e^(−35/50.8)
         = 1 − e^(−0.689)
         = 1 − 0.502
         = 0.498

ΔT_actual ≈ 54.6 × 0.498 = 27.2°C  （食月期間實際溫降）

T_min_structure ≈ T_ss_day − ΔT_actual
               ≈ −65.4 − 27.2
               ≈ −92.6°C
```

**電池最低溫（Cold Case with 0.75 W heater）：**

```
T_bat_min = T_min_structure − 5°C
          = −92.6 − 5
          = −97.6°C
```

> ❌ **嚴重超出限制**：−97.6°C 遠低於存放下限 −40°C，更遠低於運作下限 −20°C 及充電下限 0°C。

### 4.5 不同加熱功率下電池最低溫彙整

採用穩態軌道平均分析（同比例縮放估算）：

| 加熱功率 P_h | Q_in_avg | T_mean | T_min_struct | T_bat_min | 是否滿足 ≥ −20°C |
|------------|---------|--------|-------------|----------|-----------------|
| 0 W        | 9.07 W  | −83.3°C | −96.7°C    | −101.7°C  | ❌ FAIL         |
| 0.50 W     | 9.50 W  | −81.7°C | −94.3°C    | −99.3°C   | ❌ FAIL         |
| 0.75 W     | 9.82 W  | −80.4°C | −92.6°C    | **−97.6°C** | ❌ **FAIL**   |
| 2.00 W     | 10.70 W | −77.9°C | −89.3°C    | −94.3°C   | ❌ FAIL         |
| 5.00 W     | 12.43 W | −73.5°C | −83.9°C    | −88.9°C   | ❌ FAIL         |

> **重要發現：** 在目前熱設計（大表面輻射散熱，無 MLI，ε = 0.8）下，
> 單靠加熱片無法達成 −20°C 電池溫度要求。問題根源在於**輻射散熱量遠大於任何合理加熱功率**。

### 4.6 需求加熱功率估算（若無其他熱設計改善）

若要維持 T_bat ≥ −20°C（結構節點需達 −15°C = 258.15 K），則需：

```
Q_out_target = ε × σ × A_total × T_target⁴
             = 0.80 × 5.67×10⁻⁸ × 0.15620 × 258.15⁴
             = 7.083×10⁻⁹ × 4.448×10⁹
             = 31.5 W

P_heater_needed ≈ Q_out_target − (Q_solar_avg + P_internal)
               ≈ 31.5 − (9.27×0.635 + 3.18)
               ≈ 31.5 − 9.07
               ≈ 22.4 W
```

> 需要約 **22 W 以上** 的加熱功率，遠超任何 CubeSat 電力預算，
> 純靠加熱片方案**不可行**。必須從**減少熱損失（MLI）**著手。

## 5. 採用 MLI 後之改善估算

### 5.1 MLI（多層隔熱）效果

若對電池模組（佔 A_total 約 20% 面積）加裝 10 層 MLI：
- MLI 等效 ε_eff ≈ 0.03（相比裸鋁 0.8，隔熱效果提升約 26.7 倍）
- 電池隔離後，其熱損失大幅降低，加熱片功率實際作用在更小熱節點上

**局部電池節點分析（MLI 包覆後）：**

若電池模組視為獨立熱節點，體積約 50×50×20 mm（2S2P 配置），
MLI 包覆後有效輻射面積減至 ~0.005 m²，ε_eff = 0.03：

```
Q_out_bat_MLI = ε_eff × σ × A_bat × T⁴
              = 0.03 × 5.67×10⁻⁸ × 0.005 × 258.15⁴
              = 8.51×10⁻¹² × 4.448×10⁹
              = 0.038 W  （極低！）

P_heater_needed_MLI ≈ 0.038 W + 傳導損失（~0.1∼0.2 W）
                    ≈ 0.2∼0.3 W
```

> **結論：採用 MLI 包覆電池後，0.75 W 加熱片足夠維持電池溫度。**

### 5.2 MLI + 加熱片組合方案評估

| 方案 | 說明 | 電池最低溫估算 | Q4 結果 |
|------|------|-------------|---------|
| A：無 MLI，0.75 W 加熱片 | 現狀 | −97.6°C | ❌ FAIL |
| B：無 MLI，增加加熱功率 | 需 >22 W，不可行 | — | ❌ FAIL |
| C：MLI 包覆電池 + 0.75 W 加熱片 | 推薦方案 | ≥ 0°C（估算） | ✅ PASS（需驗證） |
| D：MLI 包覆電池 + 0.50 W 加熱片 | 省電方案 | ≥ −5°C（估算） | ⚠️ CONDITIONAL |
| E：MLI 包覆 + 熱電偶控制加熱 | 最優方案 | 受控 0∼+10°C | ✅ PASS |

## 6. Hot Case 估算（Worst Hot Case）

### 6.1 分析條件

- β角 ≈ 90°，全日照（無食月）
- 太陽照射面：大側面（A_sun = 0.03405 m²），α_panel = 0.90（太陽能板面朝太陽）
- 內部熱源峰值：DL PA 11.25 W + 系統基線 5.0 W = **16.25 W**
- 有效 ε = 0.82（太陽能板面 ε=0.85 與鋁面 ε=0.80 混合）

### 6.2 熱平衡計算

```
Q_solar_hot = α_panel × A_sun × G_sun
            = 0.90 × 0.03405 × 1361
            = 41.7 W

Q_in_hot    = Q_solar_hot + P_internal_hot
            = 41.7 + 16.25
            = 57.95 W

T_hot⁴ = Q_in_hot / (ε_eff × σ × A_total)
       = 57.95 / (0.82 × 5.67×10⁻⁸ × 0.15620)
       = 57.95 / 7.265×10⁻⁹
       = 7.977×10⁹  K⁴

T_hot  = (7.977×10⁹)^0.25
       = (7.977)^0.25 × (10⁹)^0.25
       = 1.680 × 177.8
       = 298.7 K  =  +25.5°C
```

**電池溫度（Hot Case）：**

```
T_bat_hot = T_hot + 5°C（電池靠近熱源，溫度略高於結構均溫）
          = +25.5 + 5
          = +30.5°C
```

> ✅ **Hot Case：T_bat_max ≈ +30.5°C，低於 +60°C 上限，且在最佳充放電範圍（0∼+45°C）內。**

> 注意：上述計算為穩態均溫，PA 高功率僅在 DL 窗口期間短暫觸發（< 10 min/軌道），
> 實際溫度峰值因熱容阻尼而更低，Hot Case 裕量充足。

## 7. 加熱片功率需求評估彙整

### 7.1 Cold Case 需求分析

| 評估指標 | 無 MLI | 有 MLI（10層）|
|---------|--------|-------------|
| 電池最低溫（無加熱片） | −101.7°C | ~−30°C（估算） |
| 0.75 W 加熱片效果 | +4.1°C（至 −97.6°C） | 足以維持 > 0°C |
| 達到 −20°C 所需功率 | ~22 W（不可行） | < 0.5 W |
| 達到 0°C 所需功率 | 不可行 | ~0.3 W |

### 7.2 設計建議

**主要建議（必要）：**

1. **電池模組加裝 MLI 隔熱層**（10 層以上，Kapton + Al foil）
   - 顯著降低電池對深空的輻射損失
   - 使 0.75 W 加熱片可有效控制電池溫度

2. **加熱片控制邏輯**（ON/OFF thermostat）
   - 建議設定：T_bat < 5°C 時開啟加熱（保留 5°C 控制余量）
   - T_bat > 15°C 時關閉加熱（避免過熱）
   - 控制器由 EPS 或 OBC 實現

**次要建議（強烈建議）：**

3. **溫度感測器**：電池模組安裝 2 個 NTC 熱敏電阻（redundant）
4. **D-004 v3 加熱片功率修正**：將 Power Budget 中加熱片功率從 0.5 W 更新至 0.75 W，
   並確認 Cold Case 平均耗電（36.5% 食月期間開啟）= 0.75 × 0.365 = 0.27 W，
   加入功率預算

## 10. 假設與限制

1. **集總熱容模型限制**：忽略衛星內部溫度梯度，實際最低溫可能更低（電池接近外殼）
2. **SafeMode 姿態假設**：假設大側面朝太陽（偏樂觀）；若端面朝太陽，Cold Case 更嚴酷 20%
3. **MLI 效果未計算傳導**：MLI 僅考慮輻射抑制，未建模電池板與結構間固體傳導
4. **PA 占空比**：Hot Case 分析假設 DL PA 持續全功率（保守上限），實際 PA 只在 Contact 時段運作
5. **本文件為 v1 初步評估**，結果需 v2 多節點熱模型確認
