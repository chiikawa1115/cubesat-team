## 4. DL 鏈路閉合分析

### 4.1 問題根源

```
需要 DL Margin ≥ 3 dB：
  所需 C/N₀_DL ≥ 5.5 + 47.0 + 3.0 = 55.5 dBHz
  最佳（80° 仰角）C/N₀_DL = 52.4 dBHz
  缺口：55.5 - 52.4 = 3.1 dB

若接受 Margin = 0 dB：
  所需 C/N₀_DL ≥ 52.5 dBHz
  80° 仰角 C/N₀_DL = 52.4 dBHz → 差 0.1 dB（極其接近）
  
→ DL 在 80° 近天頂時幾乎可以閉合（Margin ≈ 0 dB）
```

### 4.2 DL 閉合補充措施

以下任一措施可使 DL 在 ≥ 60° 達到 Margin ≥ 3 dB：

| 措施 | 增益 | 代價 |
|-----|------|------|
| 地面站升至 2.4m 碟（+32 dBi）| +1.9 dB | 地面段硬體成本 |
| 衛星 TX 增加 6 dB（5W PA）| +6 dB | 功耗 +4W，熱控更新 |
| 地面站 LNA 降噪（NF 0.5 dB）| +0.8 dB | 低噪聲前端升級 |
| **啟用 HARQ（停止等待 ARQ）** | **+3-6 dB 等效**（最多 6 次重傳）| FSW 修改 |

**推薦：啟用 HARQ（C-007 FSW 已有 CCSDS 封包框架，可擴充重傳機制）**
→ 不增加硬體成本，HARQ 6 次合並增益 +7.8 dB（10log10(6)）

```
DL 加入 HARQ（最多 6 次重傳合並）：
  等效增益：7.8 dB
  @ 60° 仰角：Margin = -0.8 + 7.8 = +7.0 dB ✅
  @ 45° 仰角：Margin = -2.2 + 7.8 = +5.6 dB ✅
  @ 30° 仰角：Margin = -4.3 + 7.8 = +3.5 dB ✅
```
